# Colormaps API

The `rwthplots.cmap` module defines all RWTH colormaps and qualitative colour
sets.  Everything is registered automatically on `import rwthplots`, so you
rarely need to call these functions directly — but the factory functions are
useful when you need a colormap *object* rather than just its registered name.
